### Sobre mim

Trabalho como fullstack na Clinicorp, um software de gestão para clínicas odontológicas e de estética. No front uso React e TypeScript, com microfrontends rodando dentro de um sistema legado. No back, Node.js e NestJS no Google Cloud, com Cloud Run, Datastore e Pub/Sub.

Gosto de arquitetura, principalmente DDD, monolito modular e Clean Architecture, e de migrar sistemas legados aos poucos.

Trabalho no modelo IA First. Uso agentes (Claude Code) do planejamento ao deploy, com skills, hooks e MCPs que eu mesmo configuro, e construo ferramentas que automatizam code review e investigação de bugs. Uma pessoa sempre revisa o resultado no fim.
